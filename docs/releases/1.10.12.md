Hungarian transport 1.10.12. Fixes for the live delays, from a second review of the feature.

## Fixes

- **Stops the bus skips:** when the feed says a trip passes your boarding or destination stop by (a detour), the card no longer shows a live time there taken from an earlier stop. When the feed says it has no prediction for a stop, the card no longer shows an estimate instead.
- **Loop lines:** on a trip that calls at the same stop twice, each call now gets its own delay. Before, the second call could show the first one's delay, and the ride time could be off by the difference.
- **MÁV trains outside Budapest:** a train row from Transitous that was already live no longer gets the train's delay added a second time.
- **Feeds that only give times:** a feed that sends the predicted time without a delay now moves the row too.
- **Stalled feeds:** a feed that keeps serving a file older than 15 minutes is treated as unavailable, so old delays are not shown as live.
- **Cancelled trips:** trips the feed marks as deleted count as cancelled, like the ones it marks as cancelled.
- **Ride time:** it is now corrected against the departure the row shows.
- **Large feeds:** a feed with an unreasonable number of stop updates is refused instead of filling memory. The MÁV sources are fetched at the same time.

## Upgrade notes

- **Restart needed:** restart Home Assistant after updating, then reload the dashboard.
