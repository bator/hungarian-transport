Hungarian transport 1.10.6. A fresh MÁV route index every day, without a feed of your own. Includes fresh Volán and city GTFS indexes.

## Highlights: a daily MÁV route index

- **Fresh train routes every day.** MÁV publishes a new timetable almost daily, but the index in a release is built once a week. Now a GitHub workflow builds the pfaedle-matched MÁV index every morning (the same build and the same trip-by-trip check as the release) and publishes it with a small manifest at `https://bator.github.io/hungarian-transport/`.
- **The integration fetches it.** Shortly after startup and then about every six hours it reads the manifest, and installs the index only when its timetable is newer than the one it serves and than a MÁV feed of your own. The download must match the manifest's size and checksum, and the index must load and pass the basic checks; otherwise the current index stays and the log says why, once.
- **Nothing to run at home.** No MÁV registration, pfaedle or upload job is needed for daily train routes. A newer feed of your own, an upload or the *Rebuild MÁV route index* action still wins, as before.
- **Opt-out:** *Settings → Devices & services → Hungarian transport → Configure → Daily MÁV route index from GitHub*. Switched off, the integration sends no request to GitHub.

## Fix

- **Reauthentication** no longer drops the integration's other options.

## Privacy

- With the daily index on, Home Assistant contacts `bator.github.io` a few times a day to read a small manifest; nothing about your installation is sent.

## Upgrade notes

- **Restart needed:** restart Home Assistant after updating, then reload the dashboard.
- **Own MÁV feed or upload job:** it can stay; a newer one still wins. If you ran one only for daily freshness, it is no longer needed.
