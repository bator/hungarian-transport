Hungarian transport 1.10.8. Pick the notification service from a list, and fixes from two more code reviews, chiefly for the daily MÁV index. Includes fresh Volán and city GTFS indexes.

## Highlights

- **Pick the notification service from a list.** *Also call this service* is now a dropdown of your scripts (by name, e.g. "Központi értesítés (script.ertesit)") and notify services ("mobile_app_iphone (notify)"); a custom `domain.service` can still be typed. A stored service that no longer exists is kept and marked "(missing)" instead of blocking the form.
- **Fewer pushes:** a daily MÁV index install now only creates the Home Assistant notification. The new *Also notify about daily MÁV index installs* option sends it to your service too; new shipped timetables and a failing daily index always do.

## Daily MÁV index

- **The pfaedle index wins for the same timetable.** One rule decides which index stays when two are built from the same MÁV feed: an index matched to the rails is never replaced by one drawn along the stations, and the daily index replaces a coarse local build of the same feed. A local updater no longer rebuilds over the daily index of the same day.
- **A failed local build no longer blocks the daily index.**
- **Retries:** after a failed or busy round the integration tries again every 20 minutes (up to 6 times), and once more later in the morning when GitHub's build is late. Downloads bypass GitHub Pages' cache.
- **Notifications reach your service at startup:** the "new timetables" message after an update now waits until scripts and notify services are ready.
- **"Three days in a row" means consecutive days,** and a daily index that has not been rebuilt for three days counts as a failure, so a stopped daily build becomes visible.
- **The daily build fails loudly:** a rejected MÁV login, or a failed build while the published index is two days old, turns the run red; the published site always stays as it was.

## Departure card and planner

- **Loop lines:** a city bus arriving between the two visits of a loop line's stop is listed again.
- **Route search outages** show "not available, try again" and retry, also for stops without coordinates; timed plans (Depart/Arrive) get the city-to-rail fallback too.
- **No stale live position:** a coach GPS position older than two minutes is no longer shown as live.
- **Wall tablets** pick up the daily MÁV index within six hours instead of after midnight.
- **Smaller fixes:** a truncated route line no longer adds a stray point; cards waiting for a free request slot start as soon as one is free; fewer repeated lookups on busy boards.

## Upgrade notes

- **Restart needed:** restart Home Assistant after updating, then reload the dashboard.
- **Same MÁV feed copied again** to `/config/hungarian-transport/` is no longer rebuilt at startup; upload it or run *Rebuild MÁV route index* to force a build.
